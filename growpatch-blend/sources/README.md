# Reference data for the GrowPatch comparison

Two separately locked Paris.4 cohorts each contain four development, eight test and four confirmation sites. The input and reference directories are separate. Surface-generation programs receive only `seeds.json`, the common input arrays, and the local initialization plane. Evaluation uses the reference arrays. The central 12 native voxels around each seed are excluded from scoring. Each cohort is a set of distinct physical regions within one scan. Validation in these regions does not measure accuracy throughout the scroll.

## Manually verified meshes at 9.6 µm

The representative mesh cohort uses the public 2.4 µm scan `20260411134726` at pyramid level 2, with a computational pitch of 9.6 µm. This is the native coordinate frame for the organizer’s Paris.4 spiral patches and the level-0 array of the published M7 L2 surface prediction. The primary surface input is the byte-valued M7 array. Every candidate receives the identical crop, seed and local orientation. Predictions and CT are stored ZYX. Coordinates in both manifests and the mesh data are XYZ. [Organizer’s spiral-input conventions](https://scrollprize.org/data/datasets/spiral-input-PHercParis4-README.md)

The official reference patches have been manually verified. Their files also preserve upstream fitted atlas and machine-generated member information. These coordinates provide an independent check against each new reconstruction run, but are not de novo human tracings of all pixels. The reference points between original mesh knots use only valid published faces; missing or multivalued rays are masked. Source vertices are often spaced about 20 voxels apart. Agreement with an interpolated reference is evidence about geometry, and cannot assign a neighboring physical sheet ID. The public tracks in the same collection are machine-extracted and were excluded as reference truth. The provenance of upstream detector training was not established on these exact regions.

Selection used a salted hash ordering of a previously enumerated 22,563-entry object index, then fixed extent, graph orientation, reference support and physical separation criteria. No CT intensity, M7 prediction intensity or competing algorithm output entered primary selection. Each crop is 257 voxels on a side. No two selected patches share a recorded member. The closest pair of crop bounding boxes is separated by 452.55 voxels. The 16 sites were fixed before development measurements. The frozen seed-manifest SHA-256 is `6795888c093ed3ca932612cff38b3dbe087348af9c869cfea63e6fa2fd69f588`. ## Hand-annotated sheet identity at 7.91 µm

In the private edition the [registered cross-sections](https://dl.ash2txt.org/full-scrolls/Scroll1/PHercParis4.volpkg/volumetric-instance-labels/README.txt) show the original CT, the common input to both algorithms and two distinct manually named sheets at identical locations. One illustrated field has closely spaced neighboring layers. The other has a wider separation. [Figure coordinates and source IDs](manual_identity_evidence.json)

The legacy cohort uses the October 2024 harmonized volumetric instance labels. In this dataset, individual papyrus sheets have distinct manually assigned IDs, reconciled across neighboring cubes. The organizers report removing small material components during harmonization. A location with ID zero may therefore be unannotated, removed, or background. It does not establish a particular wrong sheet. A *different positive ID* is direct evidence for another annotated sheet. The target is an instance of papyrus material with thickness; the reference center surface is derived by taking the midpoint of the unique complete target-ID interval on each Y ray. Ambiguous or open-ended rays are censored. [Organizers’ instance and semantic dataset specification](https://dl.ash2txt.org/full-scrolls/Scroll1/PHercParis4.volpkg/volumetric-instance-labels/README.txt)

Each participant receives a thin, byte-valued approximation of sheet centers computed from the separately published *semantic* U-Net foreground. The common estimator places a point at the center of every positive run in Y, then smooths and quantizes the result. It has no access to instance identities. This transformation suits sheets that are locally graphs in X and Z; the benchmark deliberately selects these local orientations. The semantic input and harmonized instance boundaries have a shared upstream history. Their occupied voxel sets have IoU of 0.628–0.998 on these 16 cubes. The strongest independent evidence here is sheet ownership, not an independently traced material/air boundary. The upstream U-Net training split was unavailable.

The 16 cases were picked in deterministic hash order from the intersection of both public catalogs, using a target ID near the cube center and a prespecified support and slope test. The candidates never saw these IDs. The cubes are 256 voxels per axis and the closest bounding boxes are 257 voxels apart. Each contains 8–15 explicitly labeled sheets in addition to the target. On test site 03 another sheet is within eight voxels of 51% of the retained target midpoints; on test site 01 it is that close at 1.3%. These figures measure reference difficulty, independent of any reconstruction score. The frozen seed-manifest SHA-256 is `d5cb17fc9df0b6a7b28c84c2ad3d35a98c8ac26edbd04c5d7fb2e1f96281701a`. [Shared seeds](manual_ids/seeds.json) · [Instance assignments and raw source hashes](manual_ids/refs.json) · [All cohort QA measurements](cohort_qa.json)

The paired NRRD files name their origins in Z,Y,X order and store the first file axis fastest. Reconstructed ZYX arrays were checked against a separately hosted Scroll1A level-0 Zarr chunk in every case. The correct array order and historical scan won all 16 comparisons, with Pearson correlations of 0.961–0.978. Checks included all six axis permutations and the second historical acquisition. Both arrays and all cited source metadata have local digests. [Original Scroll1A 7.91 µm volume](https://dl.ash2txt.org/full-scrolls/Scroll1/PHercParis4.volpkg/volumes_zarr_standardized/54keV_7.91um_Scroll1A.zarr/)

## Additional prospective stress and external sets

The close-ridge and interrupted-evidence challenges draw on a fresh forty-site pool in the 9.6 µm acquisition. All forty physically disjoint candidates have different member IDs from the initial sixteen verified cases. Each has a 385³ input cube and a 160-voxel evaluation radius. Within the seed-local 97 × 97 XZ square, 169 profiles of the shared M7 predictions were inspected for an eligible seed, nearby pairs of peaks, and absence of a peak near the initial plane. Sampling rules were written before candidate ranking. The top eight all tied at a score of 0.65 with two resolved peaks on every profile and zero gaps. Salted input order broke the ties. They are a close-neighbor test. A separate group uses the four remaining seed-eligible sites with most missing near-plane peaks, respectively 29, 16, 10 and 7 of 169. The four sites were fixed before their own fitted outputs. A missing near-plane peak can also occur when a sheet bends away from that plane. These are enriched stress tests and are reported separately from representative fields. [Forty-site rule](pressure/sampling_rule.json) · [Input-only scores](pressure/input_scores.json) · [Eight close-ridge sites](pressure/seeds.json) · [Four interrupted-evidence sites](interrupted/seeds.json)

The historical external test set contains a further 16 source cubes and 16 distinct harmonized target IDs. None of these IDs had been a target in the original 16. Thirteen appeared incidentally as neighboring IDs in the old cube annotations. IDs 288, 308 and 311 were absent from all original cube masks. The cube inputs and their cells have no overlap with the original sixteen or each other. One external site met the larger separation margin. The remaining 15 used the prespecified second pass allowing face-neighbor cubes. Among discrete reference midpoints inside the scoring annuli, the closest pair across original and external sites was 42.20 voxels (0.334 mm) apart. The closest pair from different external sites was 71.07 voxels (0.562 mm) apart. Tissue across adjacent cubes can still be correlated. The nearest different labeled sheet lies within 4.6–29.7 voxels of each selected seed. The historical raw CT registration check yielded Pearson 0.967–0.981 for these cases. [External sampling rule](manual_external/sampling_rule.json) · [External seeds](manual_external/seeds.json) · [Labels and neighboring sheet distance](manual_external/refs.json) · [Scored-region separation](cohort_qa.json)

An additional audit checked 645 organizer evaluation-fiber files. From objects with an explicit matching coordinate frame it recovered 1,658 control positions, converted from native by dividing XYZ by four. Interpolated fiber curves use an algorithmic tracer and were excluded. A single control position fell within 96 voxels of any of the sixteen representative seeds. It was 53.92 voxels from the target surface. This archive provides no independent fiber-identity check for those particular patches. ## Rebuild

To reproduce one case without a local data index, use Python 3.11 or later with NumPy, SciPy, requests, numcodecs and tifffile. From the project directory run the command below, supplying a separate output directory. Other cohort names are `primary`, `pressure`, `interrupted` and `manual_external`. The replayer downloads the required original files or chunks into a separate cache, then verifies each resulting input and reference array. A clean-source replay of `manual/test_03` matched all five files, and `primary/test_03` matched all four. [Frozen array hashes](replay_hashes.json)

```console
python scripts/growbench_labels_replay.py manual test_03 --output-root ../growbench-replay
```

From the project root, run `scripts/growbench_labels.py select` only in a fresh benchmark directory, followed by `growbench_labels.py m7` and `growbench_labels.py ct`. The legacy script `scripts/growbench_labels_manual.py` locks the legacy sites and prepares both inputs. Its `--inputs` switch resumes input preparation after a lock. `scripts/growbench_labels_audit.py` independently checks both finished cohorts and measures distances to labeled competitors. Original selection, file hashes, shared initialization, physical separation and known limitations accompany the source manifests.

For the eight M7 close-ridge sites, run `scripts/growbench_labels_pressure.py select`, followed by the same script with `m7` and `ct`. Then run `scripts/growbench_labels_interrupted.py select` and its two input steps for the separate four-site check. `scripts/growbench_labels_manual_external.py` uses the initial legacy manifest to exclude previously tested target sheet IDs and raw cubes. The provenance audit recomputes separation of scored domains as well as cube bounding boxes. Every source cube can be downloaded from public URLs in the local manifests.
