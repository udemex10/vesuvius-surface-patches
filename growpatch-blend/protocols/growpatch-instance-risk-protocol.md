# Equal-risk operating points for named sheets

As a separate sensitivity, use only the original four historical development cubes to select a confidence threshold for the graph recovery and the two-route recovery. The externally reserved cubes have not been inspected for this analysis. Each contender must keep both the known wrong-sheet fraction and the wrong-or-unassigned fraction at or below the corresponding stock values on development. Try thresholds from zero to one in steps of 0.025. Choose the largest seed-connected correct area among feasible nonempty predictions. Also test stock blended halfway toward the graph where their signed depths differ by at most eight voxels and the graph meets the threshold; elsewhere keep stock. Apply exactly those operating points to the sixteen external cubes. Record an unavailable threshold if development cannot meet both error budgets. A dev-feasible threshold must still pass both error tests on external sites to support a matched-risk result.
