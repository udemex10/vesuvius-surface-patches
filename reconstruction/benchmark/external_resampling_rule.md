# Sensitivity analysis for the frozen 16-site graph comparison

This diagnostic compares the published graph output at confidence ≥0.575 with every point of the official oriented8 mesh. The unit for inference is a site. Check the named-wrong fraction (another positive sheet ID divided by all positive sheet assignments), strict error (all accepted area without the target ID divided by all accepted area) and seed-connected correct area. Recompute from the two saved meshes and native 3D ID masks using the benchmark’s published parallel-ray projections. Compare against the parent’s saved site totals.

Before calculating the sensitivity results, fix 200,000 paired whole-site bootstrap samples and repeat after grouping the geographic neighbors. Group cubes by single-linkage on Euclidean center distances of at most 512 native voxels, two source cube widths (4.05 mm). A second coarse sensitivity leaves out each absolute Z slab 4,096 native voxels wide. Report exact site win, loss and tie counts; ranges after leaving a site or a geographic group out; and the paired percentile intervals. Group resampling may vary the number of sampled sites, so scale area changes to sixteen site-equivalents. Report two-sided intervals. No threshold, fitted field, source region or algorithm changes in this check.
